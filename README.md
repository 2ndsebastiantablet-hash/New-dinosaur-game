# CLOSING TIME

Cooperative VR workplace simulator / survival horror for 5–10 players. A crew of
grocery store employees has to keep the store running for a nine-day week, ten
minutes per shift, while the customers, the building and eventually management
turn into something nobody can explain.

The full design specification is in [`docs/CLOSING_TIME_GDD.md`](docs/CLOSING_TIME_GDD.md).
It is a living document, and Amendment 1 at the end overrides any earlier section
it conflicts with.

## Status

Pre-production. This repository previously held a different, now-cancelled
project. Its files have been removed (they remain in git history). No engine
or code has been chosen yet.
